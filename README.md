# Yuqi Zhang — Portfolio Website

This folder contains the editable static HTML version of the portfolio.

## Publish with GitHub Pages

### Option 1: personal site

Create a public repository named:

```text
yuqizhang326.github.io
```

Upload `index.html` and the `assets` folder to the repository root. Then open:

`Settings → Pages → Build and deployment → Deploy from a branch`

Choose the `main` branch and the `/ (root)` folder, then save. The site will be available at:

`https://yuqizhang326.github.io`

### Editing

Edit `index.html` to change the text, colors, layout, or image paths. Keep the `assets` folder in the same location. After clicking **Commit changes** on GitHub, GitHub Pages will publish the update automatically.

## Files

- `index.html` — editable page and styles
- `assets/` — cover photo, project graphics, and Fairfax Excel screenshots
- `.nojekyll` — keeps GitHub Pages from altering the static files
